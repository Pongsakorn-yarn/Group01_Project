3D Control Room

  • ส่งออกโมเดล 3 มิติเป็นไฟล์ .GLB, .STL และ .URDF

🧭 Quick Start Guide — เริ่มต้นใช้งานใน 3 ขั้นตอน

ทำงานแบบ Offline-Ready ผ่าน Local Server โดยไม่ส่งภาพกล้องออกนอกเครื่อง
1

เตรียมฮาร์ดแวร์และเฟิร์มแวร์

ต่อแหล่งจ่ายไฟ 5V 3A–5A แยก เลี้ยงเซอร์โวพร้อมต่อสาย Common GND กับบอร์ด GOOUUU ESP32-S3-CAM และอัปโหลดไฟล์ arduino_servo_bridge.ino ลงบอร์ดให้เรียบร้อย

2

เปิดเว็บเซิร์ฟเวอร์ในเครื่อง

ดับเบิลคลิกไฟล์ start_digital_twin.bat เพื่อเปิด Local Server ที่ http://localhost:8080 แล้วเปิดใช้งานผ่านเบราว์เซอร์ Google Chrome หรือ Microsoft Edge

3

เปิดกล้อง AI หรือเชื่อม USB

เข้าสู่หน้า 3D Control กดเปิดกล้อง Hand Tracking เพื่อควบคุมด้วยมือ หรือกดเชื่อมต่อ USB WebSerial เพื่อสั่งงานมอเตอร์จริงแบบเรียลไทม์
